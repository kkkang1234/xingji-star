# 星迹 StarTrace V2 · 本地表情辅助选片

从演唱会视频中密集寻找候选，使用本地面部、人体和手部关键点模型辅助排序，再比较相邻画面。保留完整视频画面和原尺寸 PNG 导出。

## 运行

1. 解压完整目录，确保本机已安装 Node.js 18 或更新版本。
2. Windows 双击「启动星迹.cmd」，会打开本地网址。使用期间保持启动窗口开启。
3. 或在本目录运行 `npm start`，打开 http://127.0.0.1:4173/ 。无需 npm install、账号、API 密钥或运行时联网。
4. 选择视频，先试一小段；选片完成后放大查看、收藏，最后打包下载 ZIP。

V2 模型需要 HTTP 加载。不要直接双击 index.html 或 prototype.html 来测试模型；直接打开会明确降级为基础候选。prototype.html 只内联界面样式和公共代码，仍依赖同目录的其他模块与模型文件。

## 推荐体验

首次选片需载入本地模型。可直接扫描全片，或填写起止秒数。「当前前后 10 秒」便于检查一个局部片段。12 / 24 / 48 是最终推荐上限，后台实际检查更多画面；不够合适时会少选。

- 点击候选画面：跳回视频。
- 放大：检查表情。
- 附近再找：前后各 1 秒，每 0.1 秒取样，比较后收藏。
- 相似画面：展开被折叠的其他真实帧。
- 备选：查看遮挡、疑似眨眼、疑似大屏或模型把握不足的画面。
- 框选舞台分析区域：减少大屏干扰，仅改变分析区域；导出保持完整原图。框选区域固定，不会跟随人物或机位变化。

## 能力与限制

这是本地「表情辅助」版本，不是能理解所有舞台动作与人物意图的视觉语言模型。实际使用 MediaPipe 三个预训练模型，再以公开可见的规则比较人物清晰度、笑容线索、手部与眼部重叠、主要人物脸部是否可检测，以及相邻眨眼变化。

能减少一些明显误选，但不能保证动作自然、准确识别挥手、判定对视、判断每位主体是否同样突出，或可靠区分 LED 大屏。大屏/超近景规则会误伤真实近景；好图仍可从备选中收藏。多人遮挡、快速移动、小脸、侧脸会漏检或误检。

视频与截图不上传；所有模型已随包提供。收藏仅保存在当前页面内存，刷新或关闭会丢失，请先下载。源视频保持只读。当前没有账号、身份识别、人物追踪、自担裁取、地图或回忆录。

## 项目结构

- `index.html` / `style.css`：界面与样式。
- `app.js`：视频定位、截帧、收藏、ZIP 公共逻辑。
- `v2.js`：范围、扫描、模型初始化、预览与分析区域交互。
- `selection.js`：时间采样、相邻比较、分组、推荐与备选。
- `vision.js`：本地模型推理及评分规则。
- `assets/mediapipe/`：固定版本运行文件和模型。
- `server.cjs`：仅监听 127.0.0.1 的静态服务器，不接收视频上传。
- `tests/selection.test.cjs`：边界、闭眼过渡和分组测试。
- `PRD.md` / `TECH.md` / `TEST_REPORT.md`：与本次版本对应的需求、实现与验证记录。

## 开发验证

`npm run check` 检查语法；`npm test` 测试选片逻辑；`npm run build:prototype` 更新 HTML 预览。修改业务逻辑后应使用真实视频重新验证，不把单元测试等同于选片效果提升。

本仓库保存「星迹 StarTrace」V2 的可运行源码。真实演唱会视频、抽帧对比图及个人分析数据均未上传；第三方运行文件与模型来源见 THIRD_PARTY_NOTICES.md。
